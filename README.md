# ECMWF-Training

Personal workspace for exercises from the ECMWF MOOC on Machine Learning in Weather & Climate (MOOC 1-3), completed as preparation for the ECMWF training course "Machine Learning-based weather forecasting" (November 2026).

## Contents

| Folder | Topic | Notebooks |
|---|---|---|
| `mooc1/` | MOOC 1 exercises | `mooc1.ipynb`: predicting 500 hPa geopotential |
| `mooc2/` | MOOC 2 exercises | _to be added_ |
| `mooc3/` | MOOC 3 exercises | _to be added_ |

## How to run

The notebooks were written and run in Google Colab.

1. Open a notebook on GitHub.
2. Replace `github.com` with `githubtocolab.com` in the URL, or upload the file to Colab directly.
3. Run the cells from top to bottom. Required packages (e.g. `cartopy`, `xarray`) are installed in the first cell.

## Notes

- Large data files (GRIB, NetCDF) and model checkpoints are not stored in this repository.
- These are learning exercises based on the official MOOC materials. Original course content belongs to ECMWF.
